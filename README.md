# Machine Learning Regression Project

## Overview

This project focuses on building and evaluating multiple machine learning regression models for predictive analysis. The workflow includes data loading in **Google Colab**, exploratory data analysis (EDA), data cleaning, feature analysis, and implementation of different regression techniques to improve prediction accuracy.

The project demonstrates a complete end-to-end machine learning pipeline, making it suitable for showcasing practical data science and analytical skills.

---

## Objectives

* Load and preprocess the dataset using Google Colab
* Perform Exploratory Data Analysis (EDA)
* Clean and prepare data for modeling
* Conduct:

  * Univariate Analysis
  * Bivariate Analysis
  * Multivariate Analysis
* Build and compare multiple regression models
* Evaluate model performance and prediction accuracy

---

## Project Workflow

### 1. Data Loading

* Imported dataset into Google Colab
* Checked dataset structure, dimensions, and data types

### 2. Exploratory Data Analysis (EDA)

* Identified missing values and duplicates
* Analyzed statistical summaries
* Visualized distributions and relationships between variables

### 3. Data Cleaning

* Handled missing values
* Removed duplicates and inconsistencies
* Encoded categorical variables (if applicable)
* Feature scaling and preprocessing

### 4. Data Analysis

#### Univariate Analysis

* Distribution plots
* Histograms
* Boxplots

#### Bivariate Analysis

* Correlation analysis
* Scatter plots
* Pair plots

#### Multivariate Analysis

* Heatmaps
* Feature interaction analysis
* Correlation matrix visualization

## Machine Learning Models Implemented

The following regression models were trained and evaluated:

1. Linear Regression
2. K-Nearest Neighbors (KNN) Regression
3. Random Forest Regression
4. Ridge Regression
5. Lasso Regression

---

## Model Evaluation

The models were evaluated using common regression metrics such as:

* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
* Root Mean Squared Error (RMSE)
* R² Score

Performance comparison helped identify the best-performing model for prediction.
